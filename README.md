# 看见 · 山西 — See Shanxi

**山西文旅展示网站** — 以 AI 驱动山西历史文化名人"复活发声"，让游客与千年人物面对面对话。

## 六大主题

| # | 主题 | 核心体验 |
|---|------|----------|
| 壹 | **山西会说话** | AI 历史名人复活对话 — 关羽、狄仁杰、王之涣、梁思成、司马光 |
| 贰 | **悟空引路** | 黑神话悟空 IP 导游 — 27 处古建取景地，斗拱拆解 + 时间复原动画 |
| 叁 | **山河入夜** | AR 穿越平遥古城 — 实时 AR + AI 声景 + 空间音频 |
| 肆 | **晋味江湖** | AI 识别山西面食 — 12+ 种面食，增强视频 + 食谱故事卡 |
| 伍 | **手上山西** | 永乐宫壁画风格迁移合影 — AI 复活口播 + 社交内容 |
| 陆 | **节气山西** | 生日 → 节气身份证 — 山西地标/非遗/物产映射 |

## 技术栈

- 纯静态 HTML/CSS/JS，无需构建工具
- Three.js 3D 交互
- CSS 动画 + 滚动驱动
- 视频背景 + 粒子系统
